## 我们的方向

- 为个人电脑和日常硬件构建高效的 AI 基础设施
- 打造能够跨模型、工具、应用和设备持续协作的持久化个人智能体
- 充分利用用户已有的本地算力，减少持续云端调用和长期使用成本
- 将研究成果转化为实用、普惠的 AI 系统

## 关于灵机一梦

灵机一梦致力于让先进 AI 以更普惠、更经济的方式服务于每一个人。我们希望充分发挥
用户已有设备的计算能力，让 AI 在日常硬件上高效运行，并降低长期使用 AI 的成本。

我们的核心产品仍在持续开发中。这个 GitHub Organization 公开部分研究成果、开发
项目和可复用资源。各项目的当前状态、贡献方式、支持范围和许可证，以对应仓库中的
说明为准。
